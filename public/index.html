    Server Time Zone

    Timezone used for server-side date math (when the daily quote rolls over, when automation rules check their schedules, when task reminders fire, when mail retention decides what's "this week"). All user-facing timestamps — activity logs, document dates, mail, photos, notes, history — render in each viewer's local timezone regardless of this setting.

    Import data from OnlyOffice, export Sietch data for backup or migration, and configure scheduled backups with remote destinations.

    OnlyOffice Import

    Pull data from an OnlyOffice CRM instance. Requires admin credentials. Imports are one-way; nothing is pushed back.

    Export Sietch Data

    Download your CRM data for backup, migration, or portability. No credentials are included in exports.

    History attachments (~33 GB) are excluded from browser downloads — restore those from a scheduled sietch-data-*.tar.gz artifact. Each part is independently restorable; import them in any order.

    JSON: ZIP with all tables as JSON + linked files. Human-readable, compatible with other CRMs.

    SQL: PostgreSQL dump for fast restore. Requires pg_dump (postgresql-client).

    Import / Restore

    Restore from a previously exported file. JSON imports skip existing records. SQL restore executes the dump directly.

    Warning: This runs raw SQL against the database. Use only trusted backup files.

    Scheduled Backups

    Automatic database backups on a recurring schedule. Backups are stored locally and optionally sent to a remote server.

    Remote Destination — Send each backup to another server after creation. Requires SSH key-based auth.

    Backup Notifications — Get notified when backups succeed or fail. Uses your account email and linked Telegram chat.
